# Undertale на Linux: плавные кадры до 144 FPS, управление в русской раскладке, WASD

Моды для **нативной Linux-версии Undertale из Steam**:

- **Плавность.** До 144 кадров в секунду, но не выше частоты экрана. Логика игры остаётся на родных 30 тиках в секунду, поэтому скорость игры, бои и таймеры не меняются. Промежуточные кадры дорисовываются интерполяцией.
- **Раскладка.** W/A/S/D/Z/X/C работают, даже когда включена русская (или любая другая) раскладка.
- **WASD (по желанию).** Ходьба на W/A/S/D вместо стрелок, стрелки при этом тоже работают.

> Файлов игры здесь нет и не будет: нужна своя копия Undertale из Steam. Моды ставятся поверх неё одной командой и так же убираются.

## Требования

- Linux x86_64 и Steam.
- **Undertale из Steam, нативная Linux-версия.** Steam ставит её по умолчанию. Если в свойствах игры включён Proton, выключите его (Свойства → Совместимость) и переустановите игру.
- X11 или Wayland (KDE, GNOME и т.д.; на Wayland игра работает через XWayland).
- Для WASD нужны `curl` и `unzip`: установщик скачивает UndertaleModTool.
- Для сборки из исходников нужен `gcc` с поддержкой `-m32`, но это необязательно: в релизе уже есть собранные библиотеки.

Проверено на Intel (Mesa) + KDE Plasma (Wayland), экран 85 Гц.

## Установка

1. Скачайте `undertale-linux-smooth-*.zip` со страницы **Releases** этого репозитория.
2. Распакуйте и откройте терминал в получившейся папке:
   ```bash
   unzip undertale-linux-smooth-v1.0.zip
   cd undertale-linux-smooth
   ```
3. **Закройте Undertale**, если она запущена, и выполните одну из команд:
   ```bash
   ./install.sh          # плавность + раскладка
   ./install.sh --wasd   # то же самое + ходьба на WASD
   ```
   Установщик сам найдёт игру во всех библиотеках Steam. Если игра лежит в необычном месте, укажите папку вручную:
   ```bash
   ./install.sh --dir "/путь/к/steamapps/common/Undertale"
   ```
4. Запустите Undertale из Steam как обычно.

### Если у вас русификатор

Сначала поставьте русификатор, потом этот мод. Патч WASD меняет данные игры (`assets/game.unx`): если поставить русификатор позже, он перезапишет патч. В этом случае просто выполните `./install.sh --wasd` ещё раз. Плавность и раскладка от русификатора не зависят.

## Как понять, что работает

- В движении (ходьба, прокрутка камеры) картинка заметно плавнее.
- Журнал лежит в `…/steamapps/common/Undertale/linux-smooth/smooth.log`. В первых строках должно быть `vblank source …` и `ghost target …`.

## Настройки

Задаются в Steam: Undertale → Свойства → Общие → **Параметры запуска**.

| Параметры запуска | Что делает |
|---|---|
| `SMOOTH_FPS=60 %command%` | предел кадров (по умолчанию 144) |
| `SMOOTH_FPS=0 %command%` | выключить плавность (раскладка и WASD остаются) |
| `SMOOTH_MODE=extrap %command%` | меньше задержка ввода, но при резкой остановке возможен лёгкий «перелёт» |

Параметры можно комбинировать: `SMOOTH_FPS=120 SMOOTH_MODE=extrap %command%`.

## Удаление

```bash
./uninstall.sh          # убрать плавность и раскладку
./uninstall.sh --wasd   # и вернуть оригинальные данные игры (отменить WASD)
```

Можно и через Steam: Свойства → Установленные файлы → **Проверить целостность файлов**. Steam вернёт оригинальные файлы, а оставшиеся папку `linux-smooth` и файл `runner.real` можно удалить вручную.

## После обновления игры или проверки файлов

Steam заменяет `runner` и `assets/game.unx`, и моды отключаются. Просто запустите `./install.sh` (или `./install.sh --wasd`) ещё раз.

## Известные ограничения

- **Задержка ввода.** В обычном режиме картинка отстаёт от игры примерно на один тик, это 30–45 мс: такова цена интерполяции. Если в боях мешает, попробуйте `SMOOTH_MODE=extrap`.
- **Alt+Tab.** Пока окно игры не в фокусе, промежуточные кадры выключены, чтобы скрытое окно не подвисало. Когда вернётесь в игру, они включатся сами.
- **Частота.** Не выше частоты обновления экрана: на мониторе 85 Гц будет 85 FPS, на 144 Гц будет 144.
- **Только нативная Linux-версия Undertale.** Windows-версия через Proton и Deltarune не поддерживаются.
- **Мод экспериментальный.** Если что-то выглядит странно, см. следующий раздел.

## Если что-то не так

- Чтобы временно выключить плавность, укажите в параметрах запуска `SMOOTH_FPS=0 %command%`.
- Чтобы записать проблемные кадры, укажите `SMOOTH_CAPTURE=1 %command%` и нажмите в игре **F9** сразу после того, как увидели артефакт. Последние 48 кадров сохранятся в `linux-smooth/capture-*`. Приложите их и `smooth.log` к issue.
- Режим самопроверки `SMOOTH_SELFTEST=1 %command%` сравнивает повтор кадра с оригиналом и пишет в журнал число различающихся байт. Должно быть 0.

## Как это работает

Undertale написана на GameMaker 1.4, и её логика жёстко привязана к 30 кадрам в секунду. Если просто поднять FPS, игра ускорится. Поэтому логика не трогается вообще, а дорисовывается только картинка. Всё делают две маленькие библиотеки, которые подгружаются в игру через `LD_PRELOAD`. Скрипт `runner` запускает настоящий движок `runner.real` с ними.

**`smooth.so`:**

1. Перехватывает вызовы OpenGL движка и записывает, что рисуется в каждом настоящем кадре.
2. Делит каждый спрайт кадра на один из трёх видов:
   - неподвижный в мире (плитки, дома), он едет вместе с камерой;
   - неподвижный на экране (текст, интерфейс);
   - движущийся объект, его движение находится сопоставлением с тем же спрайтом в прошлом кадре.
3. Движок ждёт следующего тика в цикле ожидания. В эти паузы прослойка повторяет записанный кадр, сдвигая спрайты на нужную долю их движения, и выводит его в такт аппаратной развёртке экрана (её время берётся из ядра через DRM).
4. Всё, что открывается у края экрана при сдвиге камеры, дорисовывается из предыдущего кадра. Сдвиги округляются до целых пикселей, чтобы пиксельная графика не дрожала.

Время, которое прослойка тратит на промежуточные кадры, укладывается в собственное ожидание движка, поэтому игра не замедляется. Если композитор начинает тормозить вывод (окно скрыто), прослойка на время переходит на обычные 30 кадров.

**`layoutfix.so`.** Движок определяет клавишу по символу, который она даёт в текущей раскладке, поэтому в русской раскладке W превращается в «Ц». Прослойка всегда переводит клавиши так, как в первой раскладке.

**WASD** (`wasd/wasd.csx`) — скрипт для [UndertaleModTool](https://github.com/UnderminersTeam/UndertaleModTool). Он добавляет в стартовый объект игры `keyboard_set_map` для W/A/S/D. Оригинал данных сохраняется как `game.unx.pre-wasd`.

## Сборка из исходников

```bash
make            # lib/smooth.so и lib/layoutfix.so (нужен gcc -m32)
```

`install.sh` сам собирает библиотеки, если находит 32-битный компилятор, а иначе берёт готовые из `lib/`.

## English

Mods for the **native Linux version of Undertale on Steam**:

- **Smooth frames** up to 144 FPS (capped at the display's refresh rate). Game logic stays at its original 30 ticks/s, so game speed is unchanged; in-between frames are interpolated by replaying the last frame's OpenGL commands with sprites moved along their motion, paced to the hardware vblank.
- **Layout fix**: W/A/S/D/Z/X/C work with any keyboard layout (e.g. Russian).
- **WASD** (optional): W/A/S/D act as arrow keys (patches `game.unx` with UndertaleModTool, keeps a backup).

No game files are included; you need your own copy from Steam.

```bash
unzip undertale-linux-smooth-v1.0.zip && cd undertale-linux-smooth
./install.sh            # or: ./install.sh --wasd
./uninstall.sh          # or: ./uninstall.sh --wasd
```

Steam launch options: `SMOOTH_FPS=60 %command%` (cap), `SMOOTH_FPS=0 %command%` (smoothing off),
`SMOOTH_MODE=extrap %command%` (lower input latency, slight overshoot on sudden stops).
Debugging: `SMOOTH_CAPTURE=1 %command%`, then press F9 in game to save the last 48 frames.
